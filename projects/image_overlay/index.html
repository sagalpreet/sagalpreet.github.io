What it does

✨

Tactile Paper Grain

One of the primary use cases: load the included assets/paper_grain.png overlay in cover/tile mode with low opacity to give your screen a comfortable, analog paper texture.

🎨

Multiple Display Modes

Support for Letterbox Fit, Cover Fill, 1:1 Pixel Tile, Custom Zoom Tile, and Stretch modes. Customize how your layout overlays the canvas.

⚙️

Fine-Tuned Controls

Control overlay opacity and zoom directly from the settings panel. Enable or disable overlays with a single menu bar toggle or hotkey.

🖥️

Multi-Screen Native

Automatically scales and creates transparent overlay panels across all connected displays. Customize configuration per active viewport.

Setup & Installation Instructions

Standard Install

  • Open the downloaded ImageOverlay.dmg file.
  • Drag the Image Overlay.app icon into your Applications shortcut folder.
  • Launch the app from Applications or Spotlight.

⚠ "App is damaged" Warning

As this is a self-compiled utility without Apple Developer signature, macOS Gatekeeper may restrict it on first launch.

Quick Fix via Terminal (Recommended): xattr -cr /Applications/Image\ Overlay.app Alternative Fix:

Control-click (or right-click) the application, select Open from the context menu, then confirm.
