Why StorySaver?

⚡

4-Tier Story Extraction

Extracts story media using embedded JSON metadata, DASH manifest parsing, Performance API logs, and DOM inspection fallbacks.

📸

Original Photo Extraction

Detects photo stories converted into videos due to background music and downloads the original high-resolution 1080p JPG image.

🔄

Zero-Reload Navigation

Monitors URL transitions and React DOM mutations to seamlessly re-attach the Save button across story slides automatically.

🔒

Native Background Download

Uses Chrome's native chrome.downloads API in background service worker — no CORS errors, memory leaks, or canvas hacks.

Installation instructions

Install in Chrome, Brave, Edge, or Arc browser in under 1 minute for free:

Download & Unzip Package

Click Download StorySaver ZIP above and extract the zip archive on your computer.

Open Chrome Extensions

Navigate to chrome://extensions/ in your browser address bar.

Enable Developer Mode

Toggle the Developer mode switch in the top-right corner of the Extensions page.

Load Unpacked Extension

Click Load unpacked in the top-left and select the unzipped instagram_story_downloader folder.
