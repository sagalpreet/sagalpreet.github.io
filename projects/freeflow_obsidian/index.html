FreeFlow Voice Notes

An Obsidian plugin for AI-powered voice dictation. Record your thoughts, transcribe at lightning speed with Groq Whisper, and let an LLM format your notes.

View on GitHub All utilities

Open source · Obsidian desktop and mobile · Groq Whisper Large V3

What it does

⚡

Instant Transcription

Powered by the Groq API and Whisper Large V3. Your speech is converted to text with sub-second latency, right inside your Obsidian vault.

🧠

Smart Post-Processing

Never worry about filler words again. Use built-in or custom LLM prompts to synthesize scattered thoughts, extract bullet points, and generate task lists.

📂

Seamless Integration

Write directly to a new timestamped note, append to today's daily journal, inject at your active cursor, or use multi-burst recording for long thoughts.

How to install

Get a Groq API Key

FreeFlow uses Groq's insanely fast cloud API for Whisper and Llama models. You'll need to create a free account.

Get free API key →

Install in Obsidian

Download the latest main.js, manifest.json, and styles.css from the GitHub releases page into your plugins folder.

git clone https://github.com/sagalpreet/freeflow-obsidian.git cd freeflow-obsidian npm install && npm run build

The post-processing prompt

After a recording is transcribed, FreeFlow hands the raw text to an LLM together with a prompt you control. That prompt is where the plugin earns its keep: it decides whether you get a tidied paragraph, a cheat-sheet of bullets, or something more structured.

The prompt I actually use turns several bursts of rambling speech into Obsidian revision notes — ## headings, bolded key terms, LaTeX for maths, and atomic [!CARD] flashcards pulled out of the facts worth remembering. It is written to stay faithful to what was said and to add nothing that wasn't.

Read the full prompt → — copy it into the plugin's settings as a starting point and edit it to taste.
