**This is an example, not a real recommendation.** Delete the
`places/example-recommendation/` folder once you have written a real one.

A **recommendation** is somewhere you would point a visitor to. These pins are
drawn in a warmer colour so that someone browsing the map can pick them out from
the places you have merely been.

This one sits on its own, well away from the example trip, so it shows the
recommendation marker in its own right. A recommendation that happens to share a
location with a trip stop keeps the trip's shape but takes the warm colour, so
you can still tell at a glance.
